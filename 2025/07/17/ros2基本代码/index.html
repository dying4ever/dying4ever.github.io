Synaptic Package Manager 是基于APT的图形化包管理工具，

它不仅能列出ubuntu系统中所有已经安装的程序，还可以用于安装、卸载、升级软件。

系统默认没有此工具，因此需要先通过命令行来安装它。

sudo apt update
sudo apt install synaptic
