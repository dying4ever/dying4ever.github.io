2. PLC是什么

PLC是==可编程控制器==，是一种专为工业环境设计的数字运算电子系统。它通过可编程序存储器存储逻辑运算、顺序控制、定时、计数、算术运算等程序，并通过数字量或模拟量I/O控制机械设备和生产过程。

关键词：工业环境、可编程序存储器、逻辑控制、顺序控制、定时计数、数字量/模拟量输入输出。

3. PLC的由来和发展

PLC由继电器控制系统发展而来。

继电器控制系统的问题：

  • 体积大；
  • 可靠性低；
  • 故障排查困难；
  • 硬接线逻辑复杂；
  • 生产工艺改变时适应性差。

PLC吸收了继电器控制简单直观的优点，又引入计算机系统的灵活性和通用性。

1968年，美国GM公司提出新一代控制器需求；1969年DEC公司研制PDP-14并在GM生产线上试用成功，PLC由此诞生。

4. PLC特点

特点 解释
可靠性高、抗干扰能力强 适应工业现场电磁干扰、温湿度和振动环境
通用性强、灵活性好 通过改程序适应不同工艺
功能齐全 支持逻辑、定时、计数、通信、模拟量、运动控制等
编程简单 梯形图接近继电器电路，便于电气人员理解
模块化结构 易扩展I/O和通信能力
安装调试方便 工程软件支持在线监控和诊断
维修工作量少 故障定位和更换模块方便
体积小、能耗低 适合机柜和现场设备集成

5. PLC应用领域

应用领域 说明
数字量逻辑控制 组合逻辑、顺序逻辑，如生产线、输送线、电梯
运动控制 单轴/多轴位置控制，机床、装配机器人
闭环过程控制 通过模拟量I/O和PID控制温度、压力、流量等
数据处理 数据滤波、计算、统计、记录
通信联网 分布式控制、上位机监控、DCS集成

6. S7-1200硬件结构

S7-1200主要由==CPU模块、信号板、信号模块、通信模块、HMI面板和编程软件==组成。

6.1 CPU模块

CPU模块是PLC核心，包括处理器、存储器、板载I/O、通信接口和状态指示灯。

常见外部结构：

  • 电源接口；
  • 可拆卸用户接线端子；
  • 板载I/O状态LED；
  • CPU运行状态LED；
  • PROFINET连接器。

6.2 CPU共性

PPT中强调的S7-1200 CPU共性：

  • 支持LAD、FBD、SCL等编程语言；
  • 支持存储卡转移程序；
  • 具有工作存储器、程序存储器和保持性存储器；
  • 过程映像输入/输出区；
  • 输入额定电压常见为DC24V；
  • 集成传感器/负载电源；
  • 集成2点模拟量输入，常见0~10V；
  • 支持PTO/PWM高速脉冲输出；
  • 可扩展通信模块和信号板。

6.3 CPU版本

版本 电源 DI输入 DO输出 典型用途
DC/DC/DC DC24V DC24V DC24V晶体管输出 高速开关、脉冲输出
DC/DC/Relay DC24V DC24V 继电器输出 交直流负载通用
AC/DC/Relay AC85~264V DC24V 继电器输出 交流供电现场

晶体管输出适合高速开关和PTO/PWM；继电器输出适合不同电压等级负载，但速度慢、有机械寿命限制。

7. 信号板与信号模块

7.1 信号板 SB

信号板安装在CPU前端，用于少量扩展I/O。例如数字量输入、数字量输出、混合输入输出、模拟量输出等。

特点：占空间小，适合少量扩展。

7.2 数字量I/O模块

数字量I/O模块连接在CPU右侧，用于扩展开关量输入输出。DI接按钮、行程开关、接近开关等；DO接接触器线圈、中间继电器、电磁阀、指示灯等。

7.3 模拟量I/O模块

模拟量I/O模块用于处理连续量信号，如电压、电流、温度等。

类型 典型信号 用途
AI 0~10V、4~20mA、热电阻、热电偶等 采集压力、液位、温度、流量
AO 0~10V、4~20mA 控制调节阀、变频器、模拟执行器

8. 通信接口与通信模块

8.1 PROFINET接口

PROFINET是基于工业以太网的现场总线，S7-1200通过PROFINET与编程计算机、HMI、其他PLC或工业以太网设备通信。

工程意义：PROFINET使PLC不再只是独立控制器，而是能接入工业网络和上位监控系统。

8.2 点对点通信模块

S7-1200可通过CM1241等通信模块实现RS232或RS485点对点通信，常用于连接扫码器、仪表、变频器、串口设备等。

9. TIA Portal与STEP 7 Basic

TIA Portal是全集成自动化平台，将STEP 7编程和WinCC可视化组态集成到统一工程项目中。

典型自动化系统包含：

  • PLC：控制过程；
  • HMI：操作和可视化过程；
  • 工程软件：组态硬件、编写程序、下载调试、在线诊断。

TIA Portal关键步骤：

创建项目 → 配置硬件 → 联网设备 → PLC编程 → HMI可视化组态 → 下载组态 → 在线诊断

10. 硬件组态

10.1 硬件组态任务

硬件组态是在软件中建立与实际硬件系统一致的虚拟系统，包括PLC、HMI、模块型号、订货号、版本、安装位置和通信连接。

CPU启动时会比较软件组态和实际硬件，如果不一致可能报警或进入STOP。

10.2 添加模块

在设备视图中通过拖放或双击方式，把I/O模块或通信模块放入机架插槽。模块的位置要与实际安装一致。

10.3 地址分配

地址类型 分配规则
DI/DO 通常以字节为单位分配，没有用完的位不能给其他模块使用
AI/AO 通常以组为单位分配，每个通道占一个字或两个字节

建议：一般不要随意修改系统自动分配地址，避免程序、接线和文档不一致。

10.4 数字量输入参数

数字量输入点可设置滤波时间常数。滤波时间较长可抑制抖动和干扰，但会降低响应速度。

10.5 数字量输出参数

CPU进入STOP时，可设置输出保持最后值或使用替换值。工程上要根据安全要求决定：有些设备STOP后必须断开，有些输出需要保持。

10.6 模拟量输入参数

模拟量输入模块参数包括测量种类、测量范围、积分时间、滤波等级、上下限诊断等。

  • 积分时间越长，精度越高，抗干扰能力越强，但快速性越差；
  • 为抑制工频干扰，常选择20 ms积分时间；
  • 滤波等级越高，数值越稳定，但响应越慢。

11. 模拟量转换公式

11.1 单极性线性转换

若变送器物理量范围为 (X_{min}) 到 (X_{max})，A/D数字量范围为 (N_{min}) 到 (N_{max})，则：

[ X=X_{min}+\frac{N-N_{min}}{N_{max}-N_{min}}(X_{max}-X_{min}) ]

符号 含义 单位 备注
(X) 换算后的物理量 MPa、℃、kPa等 工程实际值
(X_{min}) 物理量下限 与X一致 变送器量程下限
(X_{max}) 物理量上限 与X一致 变送器量程上限
(N) A/D转换数字值 无 PLC读取的整数
(N_{min}) 数字量下限 无 常见为0或5530
(N_{max}) 数字量上限 无 S7常见正常满量程27648

适用条件：传感器输出、模块量程与工程量之间线性对应。

物理/工程意义：把PLC中的整数转换为真实温度、压力、液位等工程量。

常见变形：

当0~10MPa对应0~27648，单位取kPa时：

[ P_{kPa}=\frac{10000N}{27648} ]

当0~High MPa对应0~27648时：

[ P=\frac{High\cdot N}{27648} ]

易错点：整数运算中应先乘后除，否则会损失精度。

11.2 4~20mA转换

4~20mA信号接入0~20mA模块时，4mA通常不对应0，而对应约5530；20mA对应27648。

若温度范围为 -100~500 ℃，要求以0.1 ℃为单位，工程量范围为 -1000~5000，则：

[ T_{0.1℃}=-1000+\frac{N-5530}{27648-5530}(5000-(-1000)) ]

工程意义：4~20mA的“活零点”能检测断线，0mA往往表示故障而不是零量程。

12. CPU系统存储器与时钟存储器

12.1 系统存储器字节

设置某个MB为系统存储器字节后，其中部分位具有特殊含义：

位 含义
首次循环位 仅在进入RUN后的首次扫描为1
诊断图形已更改位 发生诊断事件时短时间为1
始终为1位 常开触点总是闭合
始终为0位 常闭触点总是闭合

12.2 时钟存储器字节

时钟存储器字节的各个位输出不同周期的方波，可用于闪烁灯、周期采样、节拍控制等。

14. 易错点

  1. 信号板安装在CPU前端，信号模块通常安装在CPU右侧。
  2. 通信模块常安装在CPU左侧。
  3. 继电器输出和晶体管输出不能混为一谈，PTO/PWM要用晶体管高速输出。
  4. 0~20mA模块读取4~20mA信号时，4mA不对应0。
  5. 模拟量滤波越强，响应越慢。
  6. 软件组态必须与实际硬件订货号、版本、插槽位置一致。
  7. DI/DO地址按字节分配，剩余位不可随意给其他模块。

15. 考前补充：硬件组态和模拟量高频点

15.1 CPU型号与扩展能力记忆

CPU 本机数字量I/O 本机模拟量输入 扩展能力倾向
CPU 1211C 6DI/4DO 2AI 小点数、基本控制
CPU 1212C 8DI/6DO 2AI 可少量扩展
CPU 1214C 14DI/10DO 2AI 扩展能力更强，工程中更常见

考试如果不要求死记完整参数，至少要知道：型号越大，本机I/O点数、存储器和扩展能力通常越强。

15.2 数字量输入输出接线判断

  • DI输入常见额定电压为DC24V，接按钮、限位、接近开关等。
  • 晶体管输出适合DC负载和高速脉冲输出，速度快、寿命长。
  • 继电器输出适合交直流多种负载，隔离好，但速度慢、寿命受触点影响。
  • PTO/PWM、高速输出不要选继电器输出点。

15.3 模拟量换算通用式

若数字量范围为 (N_{min}\sim N_{max})，工程量范围为 (X_{min}\sim X_{max})，则：

[ X=X_{min}+\frac{N-N_{min}}{N_{max}-N_{min}}(X_{max}-X_{min}) ]

常见满量程：0~10V、0~20mA常对应0~27648；4~20mA中4mA对应工程量下限，不是“故障零点”。

16. 本章预测题与答案

题1：PLC的定义是什么？

答案：PLC是一种面向工业环境设计的数字运算电子系统，利用可编程序存储器存储逻辑运算、顺序控制、定时、计数、算术运算等程序，并通过数字量或模拟量输入输出控制机械设备和生产过程。

题2：S7-1200主要由哪些硬件组成？

答案：S7-1200主要由==CPU模块、信号板、信号模块、通信模块、HMI面板和编程软件组成==。CPU负责运算和控制，信号板/信号模块扩展I/O，通信模块扩展通信能力，HMI用于操作显示。

题3：信号板和信号模块有什么区别？

答案：信号板安装在CPU前端，适合少量扩展I/O，占空间小；信号模块安装在CPU右侧，扩展点数和类型更多，适合较大规模I/O扩展。

题4：S7-1200的三种CPU输出版本有什么区别？

答案：DC/DC/DC为DC24V供电、DC输入、晶体管DC输出，适合高速输出；DC/DC/Relay为DC供电、DC输入、继电器输出；AC/DC/Relay为交流供电、DC输入、继电器输出。继电器输出适用电压范围广但速度较慢。

题5：TIA Portal创建自动化系统的基本步骤是什么？

答案：创建项目、配置硬件、联网设备、对PLC编程、组态HMI可视化、下载组态数据、使用在线与诊断功能。

题6：硬件组态的任务是什么？

答案：在软件中建立与实际硬件一致的虚拟系统，包括PLC和HMI设备、模块型号、订货号、版本、安装位置、通信连接和模块参数。CPU启动时会比较实际硬件与软件组态是否一致。

题7：模拟量输入中27648代表什么？

答案：在S7-1200常见模拟量标准范围中，27648通常表示正常满量程100%。例如0~10V或0~20mA对应的正常数字量范围常为0~27648。

题8：压力变送器0~10MPa对应数字量0~27648，若N=13824，压力是多少？

答案：(P=10\times 13824/27648=5\text{MPa})。若以kPa为单位，(P=5000\text{kPa})。

题9：为什么4~20mA信号比0~20mA更适合工业现场？

答案：4~20mA具有活零点，4mA表示量程下限，0mA通常可判断为断线或故障，因此便于诊断；同时电流信号抗干扰能力较强，适合远距离传输。

题10：时钟存储器字节有什么用途？

答案：时钟存储器字节的各个位提供不同周期的方波信号，可用于指示灯闪烁、周期性动作、节拍控制和简单定时触发。
