# 封面与首页标题统一设计

## 问题

封面标题、转场标题和首页标题虽然引用同一个字体变量，但目前分别使用不同的栏宽、字号、填充效果和定位规则。标题内容又由脚本写成纯文本，浏览器会根据栏宽自动换行，因此封面显示两行、首页显示三行，转场过程中还会发生重新排版。

## 目标

- 三处标题固定显示为两行：`终南山下，` / `活死人墓`。
- 三处标题使用同一字体、字重、行距、字距和条纹金色效果。
- 封面与首页标题共用同一左侧基准和顶部基准；首页可以缩小，但不改变行结构。
- 转场标题只进行整体缩放与位移，不在动画中重新换行。
- 封面和首页右侧竖排文字共用字体、字号、字距和定位规范，文案可保持各自内容。

## 结构设计

标题统一增加 `site-title` 类，并由两个块级行元素组成：

```html
<span class="site-title__line">终南山下，</span>
<span class="site-title__line">活死人墓</span>
```

`renderPage` 不再直接设置标题节点的 `textContent`，而是通过一个小型渲染函数生成两行文本节点。文本内容仍来自 `SITE_CONTENT.title`，不复制第二份内容来源。

## 排版设计

- `site-title` 负责共享字体、字重、行距、字距、条纹金色和阴影。
- 封面和首页只通过 CSS 自定义属性控制字号，首页保留较小尺寸以容纳四个入口窗口。
- `cover__content` 与 `home-hero__copy` 使用同一个左侧变量和同一个顶部锚点，不再依赖不同高度内容的垂直居中结果。
- 两个容器使用相同的标题可用宽度；固定行元素避免浏览器自动重排。
- 移动端继续保持两行，只降低字号和调整统一顶部锚点。

## 竖排设计

封面 `cover__side-copy` 与首页 `home-hero__vertical` 共用相同的字体、字号、字距、右侧距离、垂直中心和书写方向。两段文字可以不同，但视觉基准一致。

## 动画衔接

转场标题沿用现有几何测量方式，从封面标题矩形移动到首页标题矩形。因为两端均为固定两行且样式共享，动画仅改变 `x`、`y` 和 `scale`，不会出现换行跳动或字体质感变化。

## 测试与验收

- 结构测试：三处标题都有共享类和两行元素。
- 样式测试：三处标题引用共享样式，首页不再定义另一套实心标题样式。
- 浏览器测试：封面与首页标题字体族一致、均为两行、左侧基准一致，转场期间标题保持两行。
- 桌面与移动端截图复核；现有开场、滚轮、四入口和减少动态效果测试继续通过。

## 范围

本次只修改标题结构、标题样式、对应位置、竖排视觉规范及相关测试，不更换字体文件，不调整首页窗口内容，也不修改原 Hexo 博客。
