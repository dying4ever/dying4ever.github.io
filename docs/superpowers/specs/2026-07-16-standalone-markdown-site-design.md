# 独立 Markdown 沉浸式博客设计

## 目标

将 `immersive` 改造成完全独立的网站。它负责沉浸式首页、内容索引、Markdown 渲染和最终静态页面生成，不再依赖或调用 Hexo。

旧 Hexo 只作为本次迁移的只读来源。迁移完成后，文章和页面只在 `immersive` 内维护。

## 范围

本轮包含：

- 一次性复制 131 篇旧 Markdown 文章及其相对资源；
- 保留旧文章日期地址；
- 新建 Notes、Film、Life、Projects 四个内容父目录；
- 新建关于我、友链、归档、分类和建站日志页面；
- 调整首页第二场景以后使用的连续山水背景；
- 重做序章排版和文字透明度；
- 生成适合桌面端和移动端的静态站点；
- 删除生产构建对 Hexo 的依赖。

本轮不包含评论系统、账号系统、在线编辑器和服务端搜索。

## 内容目录

```text
content/
├── notes/                 迁入全部旧文章
│   ├── cpp/
│   ├── ros2/
│   ├── 具身智能/
│   └── 文章名.assets/
├── film/                  后续新增影评 Markdown
├── life/                  后续新增生活 Markdown
├── projects/              后续新增项目 Markdown
└── pages/
    ├── about.md
    ├── friends.md
    └── changelog.md
```

旧文章迁入 `notes` 后保持原目录层级和 `.assets` 资源目录。以后新增内容时，作者只需把 Markdown 放进对应父目录。

## Markdown 约定

继续兼容原有 YAML front matter：

```yaml
---
title: 文章标题
date: 2026-05-10 19:35:08
sticky: 1
categories:
  - 原分类
tags:
  - 标签
desc: 简介
disableNunjucks: true
---
```

构建器读取 `title`、`date`、`sticky`、`categories`、`tags` 和 `desc`。`disableNunjucks` 被接受但不参与渲染。

Markdown 支持标题、表格、引用、任务列表、围栏代码块、行内代码、普通链接和相对图片。相对图片按 Markdown 文件所在目录解析。

## 地址与兼容性

文章继续生成：

```text
/YYYY/MM/DD/文章文件名/
```

这样旧收藏、站内链接和搜索引擎记录不会失效。分类页和父目录页使用：

```text
/notes/
/film/
/life/
/projects/
/categories/
/archives/
/about/
/friends/
/changelog/
```

Notes 显示迁入文章的原分类与标签。Film、Life、Projects 分别显示对应内容目录下的 Markdown。

## 构建架构

保留当前 Vite 首页和 GSAP 动画，新增一个 Node 静态内容构建器：

1. 扫描 `content`；
2. 解析 front matter；
3. 将 Markdown 转成 HTML；
4. 计算文章地址、分类、标签和归档数据；
5. 复制文章相对资源；
6. 通过页面模板生成内容页；
7. 运行 Vite 构建首页；
8. 将首页资源和内容页面合并到同一个 `dist`。

生产构建不再读取 `../blog`，也不再执行 Hexo 命令。

## 首页视觉与动画

封面和进入后的第一屏保留当前设计与字体。

第二场景以后使用三幅山水图形成连续空间：

1. 山路、远景人物与亭台：镜头从首页向后退，进入更开阔的谷地；
2. 河谷、亭子与小舟：用于序章与内容过渡；
3. 河谷、戏台与小舟：用于 About 和后续内容入口，强化“武侠为主、戏曲为辅”。

图像统一为相近的暖褐宣纸色、黑墨边缘和雾层密度。相邻场景通过渐变遮罩、背景位置变化和轻微缩放衔接，不出现纯黑或纯白断层。

云层和飞鸟保持轻量动画。移动端减少云层数量、禁用高成本视差，并遵守 `prefers-reduced-motion`。

## 序章布局

序章不再将多段文字重叠居中显示，改为与 About Me 相似的左右分栏：

- 左侧：`PROLOGUE · 序`、简短引导和张爱玲署名；
- 右侧：完整引用正文，按自然段纵向排列；
- 当前段落接近完全不透明；
- 非当前段落只保留极轻的明暗差，不产生明显重影；
- 窄屏改为上下排列。

## 内容页面视觉

内容页采用“深色山水页头 + 浅宣纸正文”：

- 顶部导航与首页一致；
- 页头显示标题、日期、分类和标签；
- 正文使用高对比度深墨文字；
- 代码块使用深色底和清晰高亮；
- 图片保持原比例并可在移动端自适应；
- 长文提供桌面端目录，移动端目录折叠；
- 分类、归档和父目录页使用相同纸张、线条和朱砂强调色。

页面只进行轻量入场，不复制首页的重型滚动叙事，保证阅读流畅。

## 页面职责

- `/notes/`：全部迁入文章、原分类和标签入口；
- `/film/`：影评内容；
- `/life/`：生活内容；
- `/projects/`：项目内容；
- `/categories/`：原分类聚合；
- `/archives/`：按年份和月份排列全部内容；
- `/about/`：渲染 `content/pages/about.md`；
- `/friends/`：渲染 `content/pages/friends.md`；
- `/changelog/`：渲染建站日志 Markdown，并按日期展示版本记录。

## 异常处理

- 缺少标题或日期：构建失败并输出文件路径；
- 地址重复：构建失败，列出冲突文章；
- 图片不存在：构建继续，但输出明确警告；
- 空目录：对应父目录页显示准备中的空状态；
- 无法解析的 front matter：构建失败，不静默丢失文章。

## 性能与适配

- 背景资产输出 WebP，桌面最大宽度 1920px；
- 首屏优先加载，后续三幅背景延迟加载；
- 内容页不加载首页 GSAP 时间线；
- 图片默认懒加载并提供尺寸约束；
- 桌面、平板和手机分别校验布局；
- 首次加载目标小于 2 秒，滚动过程中避免布局抖动。
