# 首页连续滚动、序章与 About 设计

## 目标

在不重做封面、主页入口和 Markdown 内容链路的前提下，把“主页 → 山水标题 → 序章 → About Me”整理为同一个连续的滚动长镜头。序章按用户标注调整排版，About 直接承接序章并加入头像；云、花瓣与雪作为轻量动态意象贯穿场景。

## 长镜头结构

- `#scroll-story` 继续是唯一的桌面端 sticky 滚动舞台，并从三幕扩展为四幕：主页、山水、序章、About。
- `#about-story` 移入 `.scroll-story__sticky`，不再等 sticky 场景结束后突然切换为独立背景。
- 序章结束后不再回显上一张山水图；河流、舟、纸纹和雾层继续向下推进，About 在同一画面中由暗至明出现。
- About 完整出现后，sticky 舞台再释放到现有深色内容总览；About 背景底部继续渐变到总览的松烟黑。

## 序章排版

- 中段标题“山水退远，文字渐近”在桌面与移动端均保持一行，字号随可用宽度缩放。
- 左栏保留 `PROLOGUE · 序`，大标题改为“出名要趁早呀”。每个字使用独立字符元素从上到下排列，并通过小幅水平偏移与旋转形成蜿蜒书写路径。
- 标题使用鲜明但不荧光的朱砂红，字号明显大于当前标题，并在进入序章时逐字显现。
- 删除左栏说明段落。
- 右栏三段正文均首行缩进 `2em`。
- 第二段中的“呵，出名要趁早呀！来得太晚的话，快乐也不那么痛快。”使用语义化 `mark` 元素，旧金底色、深墨文字并加粗。
- “——张爱玲《传奇》”移到右栏正文下方并右对齐。

## 动态意象

- 新增一个属于 sticky 舞台的 `journey-atmosphere` 层，置于背景与正文之间且不接收指针事件。
- 云：两层大范围柔雾缓慢横移，并随滚动从山水幕延续到 About。
- 花瓣：少量朱砂花瓣在序章出现，沿弧线下落和旋转，不遮挡正文。
- 雪：在序章进入 About 时逐渐出现，数量克制，随 About 变亮后淡出。
- 桌面端由 GSAP 时间轴控制阶段透明度和位移；移动端使用静态顺序与极轻 CSS 漂移；`prefers-reduced-motion` 下停止粒子与视差并保留完整内容。

## About 承接

- About 使用现有 `content/pages/about.md` 中“曾阿牛”段落的核心内容：名字来源、自我坐标，以及两条简短说明。
- 将旧站的 `head.webp` 只读复制为新项目 `public/images/about-avatar.webp`；旧 Hexo 文件保持不变。
- 头像以旧照片式小幅偏转和旧金细框嵌入 About 左侧，与姓名、说明和“读完整介绍”链接组成一组；右侧保留“自此，我要写……”展示文字。

## 响应式与性能

- 桌面细指针设备使用完整 scrub 长镜头。
- `max-width: 768px` 或粗指针设备按主页、山水、序章、About 自然纵向排列，不锁定长滚动，也不隐藏正文。
- 粒子总量保持克制，只动画 `transform` 和 `opacity`；不新增网络依赖或大体积素材。
- 六个标题字符仍由一个语义标题和准确的 `aria-label` 表达，装饰性单字对辅助技术隐藏。

## 验收

- 序章标题鲜红、放大、竖向蜿蜒且文字准确。
- 三段正文首行缩进两格，高亮完整包含“呵，”，署名位于右栏下方。
- 山水标题一行显示。
- 桌面滚动中序章直接进入 About，不回闪上一幕；头像加载成功。
- 云、花瓣、雪阶段正确且不遮挡文本；移动端无横向溢出；减少动态效果可用。
- `npm test`、`npm run build` 和 `python tests/smoke.py` 全部通过后交给用户本地确认，不提交、不部署。
